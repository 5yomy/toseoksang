# 토석상 土石桑 — 홈페이지

단양 방곡도예촌 독채한옥 **토석상** 안내 홈페이지입니다.
서버나 프로그램 설치 없이 동작하는 정적 사이트입니다.

## 지금 바로 보기

`index.html` 을 더블클릭하면 브라우저에서 열립니다.

## 파일 구성

```
site/
├── index.html          메인 (히어로 · 이름풀이 · 소개 · 객실 · 특장점 · 전경 · 여행 · 예약)
├── rooms.html          객실안내 (토석상 · 고흐의 방 · 방곡숲 · 부지 전체 대여)
├── reservation.html    예약안내 (절차 · 요금표 · 이용안내 · 환불규정)
├── travel.html         단양 여행 (가볼 곳 · 맛집 · 1박 2일 코스)
├── location.html       오시는길 (지도 · 주소 · 교통편)
├── css/style.css       디자인 전체
├── js/
│   ├── site-config.js  ★ 펜션 정보 — 여기만 고치면 전 페이지 반영
│   └── main.js         메뉴 · 슬라이드 · 스크롤 효과
└── images/             사진 38장 (사장님 네이버·블로그 사진에서 가져옴)
```

## 사진에 대해

사진 38장은 모두 **사장님이 직접 올리신 것**만 골라 넣었습니다.

| 출처 | 장수 | 비고 |
|---|---|---|
| 네이버 예약 · 플레이스 등록사진 | 대부분 | 4032×3024 원본 — 히어로·배너에 사용 |
| 네이버 블로그 `banggok4052` | 나머지 | 900~1440px — 고흐의 방 · 방곡숲 · 여행지 |

- **방문자 리뷰 사진은 쓰지 않았습니다.** 손님이 올린 사진이라 저작권이 사장님께 없습니다.
- **손님 얼굴이 나온 사진도 뺐습니다.** 칠순·팔순 잔치 단체사진이 여러 장 있었지만,
  홈페이지에 올리려면 찍힌 분들의 동의가 필요합니다.
- 인스타그램(@tosuksang)은 로그인 없이 최근 12개·640px 까지만 열려서 쓰지 않았습니다.
  더 좋은 화질의 원본이 있으시면 `images/` 의 같은 이름으로 덮어쓰시면 됩니다.

사진을 바꾸고 싶으시면 `images/` 에 **같은 파일 이름**으로 덮어쓰면 코드 수정 없이 반영됩니다.
권장 용량은 한 장당 300KB 이하입니다. (squoosh.app 에서 품질 75%로 저장)

## 해야 할 일 (공개 전 체크리스트)

### 1. 반드시 채워야 하는 것

| 항목 | 위치 | 현재 상태 |
|---|---|---|
| **객실 요금** | `reservation.html` | `000,000` — 임의로 적으면 분쟁이 생길 수 있어 비워두었습니다 |
| **면적 · 인원** | `rooms.html`, `index.html` | `○○평`, `○인` |
| **대표자 성명** | `js/site-config.js` 의 `ceo` | `○○○` — 공개된 자료에 없었습니다 |
| **입금 계좌** | `js/site-config.js` 의 `bank`/`account`/`accountName` | 계좌이체를 받지 않으시면 `reservation.html` 의 계좌 안내를 지우세요 |

### 2. 확인이 필요한 것

- **환불 규정의 기준일** — 네이버 예약에 *등록된 환불정책*은 **14일**, 같은 페이지의
  *예약 안내문구*는 **10일** 로 서로 다릅니다. `reservation.html` 에는 등록된 정책(14일)을
  넣고 눈에 띄는 안내를 달아두었습니다. 맞는 쪽으로 정리해 주세요.
- **고흐의 방 평일 전용 / 연박 할인** — 블로그(2025. 8.)에 "평일만 예약가능",
  "연박 시 1박당 10만원 할인 이벤트중" 이라고 되어 있었습니다. 지금도 유효한지 몰라
  사이트에는 넣지 않았습니다.
- **본채 반려동물** — 고흐의 방·방곡숲은 동반 가능으로 적었습니다. 본채는 안내사항에
  "반려견 적발 시 강제 퇴실" 이라 되어 있어 불가로 보고 표기하지 않았습니다.

### 3. 이미 채워 넣은 것 (네이버 예약·플레이스에서 확인)

- 사업자등록번호 `661-17-01802`
- 실시간예약 링크 — 온다 `booking.pension.onda.me/137862/calendar`

- 어메니티 · 이용규칙 · 추가인원 5만원

## 인터넷에 올리는 방법

가장 간단한 무료 방법은 **Netlify Drop** 입니다.

1. <https://app.netlify.com/drop> 접속
2. `site` 폴더를 브라우저 창에 끌어다 놓기
3. 바로 주소가 생깁니다 (`○○○.netlify.app`)
4. 도메인을 사셨다면 Netlify 설정에서 연결

올리기 전에 `index.html` 의 `<link rel="canonical">` 주소를 실제 주소로 바꿔주세요.
